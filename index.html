🆓 CallMeBot GRATIS - Panduan Lengkap

✅ 100% GRATIS Selamanya!
Tidak perlu kartu kredit, tidak perlu Fonnte. Langsung kirim ke GRUP WA.
Langkah 1: Daftar CallMeBot (2 menit)
  1. Simpan nomor +34 644 10 55 84 di HP → nama: CallMeBot
  2. Buka WA → chat ke CallMeBot → kirim: I allow callmebot to send me messages
  3. Tunggu balasan dapat APIKEY 6 digit (contoh: 123456) → COPY
Langkah 2: Add Bot ke Grup WA (1 menit)
  1. Buka grup WA AREA EF → Add participant → cari CallMeBot → Add
  2. Di grup ketik: !groupid atau @CallMeBot !groupid
  3. Bot balas ID grup seperti 120363025106234567@g.us → COPY
Langkah 3: Paste ke Google Script (2 menit)
  1. Buka script.google.com → buka project kamu
  2. Buka file GOOGLE_SCRIPT_CALLMEBOT_GRATIS.js yang saya kasih
  3. Ganti:
    PHONE_OR_GROUP_ID: '1203630xxx@g.us'
    APIKEY: '123456'
  4. Save → Run setupTriggerGratis() → Authorize
  5. Run testKirimGratis() → cek grup WA, harusnya masuk!
🔧 Test dari Admin?
💡 Tips: Jika CallMeBot tidak balas groupid, coba kirim !groupid tanpa @, atau pastikan bot sudah jadi anggota grup minimal 5 menit.
